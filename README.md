# Student Marks Analysis using NumPy

## 📌 Project Overview

This is a beginner-friendly Python project built using NumPy.

The project analyzes the marks of students across multiple subjects and calculates important statistics such as total marks, average marks, highest and lowest scores, ranking, pass/fail status, and subject-wise performance.

## 🎯 Objectives

* Analyze student marks using NumPy
* Calculate total and average marks
* Find the highest and lowest performers
* Analyze subject-wise performance
* Rank students based on their average marks
* Identify high and low-performing students
* Calculate statistical measures

## 🛠️ Technologies Used

* Python
* NumPy

## 📚 NumPy Concepts Used

* NumPy Arrays
* 1D and 2D Arrays
* Array Shape
* `np.sum()`
* `np.mean()`
* `np.max()`
* `np.min()`
* `np.argmax()`
* `np.argmin()`
* `np.std()`
* `np.median()`
* `np.argsort()`
* Boolean Masking
* Axis (`axis=0` and `axis=1`)

## 📊 Analysis Performed

The project performs the following analysis:

1. Displays student and subject information
2. Calculates total marks for each student
3. Calculates average marks for each student
4. Finds the topper
5. Finds the lowest scorer
6. Calculates subject-wise average marks
7. Finds highest and lowest marks in each subject
8. Identifies students scoring above 75
9. Identifies students scoring below 60
10. Determines pass/fail status
11. Calculates standard deviation
12. Calculates median marks
13. Generates student rankings
14. Finds the best-performing subject
15. Finds the lowest-performing subject

## 🚀 How to Run

1. Install Python.
2. Install NumPy if it is not already installed:

```bash
pip install numpy
```

3. Run the Python file:

```bash
python student_marks_analysis.py
```
